## Priority Issues

### [P0] No product imagery on homepage
The hero section is text-only. For a marketplace selling visual design files, the homepage should showcase the product immediately. Designers buy with their eyes.
- **Fix:** Hero section with a curated grid of 4-6 product thumbnails or featured product showcase.
- **Command:** `$impeccable bolder`

### [P1] Generic color system with no brand identity
Stock dark navy primary. Success/warning bolt-on tokens. For a product targeting designers, the visual identity should signal design competence.
- **Fix:** Define a distinctive brand palette with one saturated accent color.
- **Command:** `$impeccable colorize`

### [P1] Zero keyboard shortcuts or power-user features
No command palette, no keyboard navigation beyond tab, no bulk download. For professional designers who work fast, this is friction.
- **Fix:** `/` for search, `Esc` to close, `Cmd+K` command palette.
- **Command:** `$impeccable harden`

### [P2] Error handling is toast-only with no recovery path
Every failure produces a generic toast. No inline validation, no retry buttons, no specific error messages.
- **Fix:** Inline validation on forms, retry buttons on API failures, specific error messages.
- **Command:** `$impeccable clarify`

### [P2] Identical card grids throughout
Features, categories, testimonials, pricing, dashboard stats — all use the same Card structure. Visual monotony.
- **Fix:** Break the pattern with varied layouts.
- **Command:** `$impeccable layout`

## Persona Red Flags
